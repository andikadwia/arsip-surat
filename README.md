# DigiSurat

DigiSurat is a web-based application for managing and archiving incoming and outgoing letters. The application also provides an AI-based classification feature to help organize letters automatically.

DigiSurat has two user roles: "Admin" and "Employee". Each role has different access according to its responsibilities.

## User Roles

### Admin

Admin is responsible for managing the main features of DigiSurat, including letters, categories, users, AI settings, and archive reports.

### Employee

Employee can access the available letter archives, view letter details, and download letter files when needed.

## Login

Admin and Employee use the same login page.

To log in:

1. Open DigiSurat in a web browser.
2. Enter the registered username.
3. Enter the password.
4. Click "Login".
5. The system will open the dashboard based on the user's role.

If the login fails, check the username and password and make sure that Caps Lock is not active.

## Admin

After logging in as Admin, the system displays the Admin Dashboard. The dashboard provides an overview of the letters and users stored in the system.

### Managing Letters

Admin can add and manage letters through the "Manajemen Surat" menu.

To add a new letter:

1. Open "Manajemen Surat".
2. Click "Unggah".
3. Select and upload the letter file.
4. The system processes the uploaded file and automatically fills in the available letter information.
5. Check the information generated by the system.
6. Check the classification result provided by the AI feature.
7. If necessary, make adjustments to the available data.
8. Click "Simpan" to save the letter to the archive.

The saved letter will then be stored in DigiSurat and can be accessed by users according to their role.

Admin can also edit existing letter data and delete letters that are invalid or duplicated.

### Letter Categories

Admin can manage letter categories through the "Kategori Surat" menu.

The available categories are used to organize the archived letters. Admin can add, edit, or delete categories when necessary.

### User Management

Admin can manage user accounts through "Manajemen User".

Admin can:

1. Add a new Admin or Employee account.
2. Set the user's role.
3. Edit user information.
4. Change a user's role when necessary.
5. Remove users who are no longer needed.

### AI Settings

DigiSurat uses AI to help classify uploaded letters automatically.

Admin can manage the AI feature through "Pengaturan AI". This section is used to check the AI model status and perform AI training.

AI training can be performed again when additional letter data is available. The training process is used to update the model using the available data.

DigiSurat also provides "Perbandingan Algoritma", which can be used to compare the performance and evaluation results of the classification algorithms used in the application, including Naive Bayes and K-Nearest Neighbor (KNN).

### Archive Reports

Admin can generate archive reports through "Laporan Arsip".

The available filters can be used to select the required archive data, such as the date, category, or letter type. The report can then be exported in PDF or Excel format.

## Employee

Employee has more limited access than Admin. The main purpose of the Employee role is to access the archived letters needed for work.

### Viewing Letters

After logging in, Employee can view the available letters from the Employee Dashboard.

To view a letter:

1. Open the Employee Dashboard.
2. Find the required letter.
3. Click "Detail".
4. Review the available letter information.

### Downloading Letters

Employee can download a letter file when it is needed.

To download a letter:

1. Find the required letter.
2. Open the letter details if necessary.
3. Click "Download".
4. The letter file will be downloaded to the device.

Employee does not have access to the main management features such as "Manajemen User", "Pengaturan AI", and other Admin-only features.

## Logout

After finishing the work, click "Logout" to end the session. Users are recommended to log out, especially when using DigiSurat on a shared computer.

## Application Usage Summary

In normal use, the Admin starts by logging in and managing the letter archive. When a new letter is received, the Admin uploads the letter file through "Manajemen Surat". DigiSurat then processes the uploaded file and fills in the available information automatically. The Admin checks the generated information and AI classification result before clicking "Simpan".

After the letter has been stored, Employees can access the available archive, view the letter details, and download the letter file when needed.

The Admin also manages the categories and user accounts, maintains the AI through "Pengaturan AI", compares the available classification algorithms through "Perbandingan Algoritma", and creates archive reports through "Laporan Arsip".

The available features depend on the user's role. Admin has access to the system management features, while Employee focuses on accessing, viewing, and downloading archived letters.
